# Jagannadh K 

Personal software engineering portfolio

## Development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
```

Deploy the `dist` directory as a static site. The site expects hosting at the domain root (Vercel or Netlify defaults work). Build command: `npm run build`; output: `dist`.

## Editing

- Content: `src/data/portfolio.ts`
- Resume: `public/assets/Jagannadh_K_Resume.pdf`
- Portrait: `portrait.png`, then `npm run images`

Content comes from Jagannadh’s supplied resume. Project metrics describe the experience reported in that resume. Credentials are listed without verification links because none were supplied.

The portrait, contact details and resume are intentionally included at the owner’s request. Fictional streaming-inspired presentation; no streaming-service affiliation.
